📋 Описание проекта

Taberu (食べる — «есть» по-японски) — это одностраничный сайт (landing page) для сервиса доставки аутентичной японской еды. Проект создан в учебных целях для демонстрации навыков:

- Семантической вёрстки HTML5
- Адаптивного дизайна на чистом CSS (CSS Custom Properties, Flexbox)
- Интерактивности с помощью Alpine.js (без jQuery и тяжёлых фреймворков)
- SEO-оптимизации и Open Graph разметки
- Работы с Git/GitHub

**🎯 Цель проекта:** Показать, как создать современный, отзывчивый и интерактивный сайт, используя минималистичный JavaScript-фреймворк Alpine.js.

## ✨ Функционал

### 🎨 Визуальная часть
- Адаптивный дизайн (Mobile First) с тремя брейкпоинтами
- Плавные анимации появления элементов
- Интерактивное меню-бургер для мобильных устройств
- Визуальная обратная связь при наведении (hover-эффекты)

### ⚡ Интерактивность (Alpine.js)
- **Мобильное меню** — открытие/закрытие по клику
- **Фильтрация блюд** — переключение между категориями (Sushi, Ramen, Sashimi и др.)
- **Слайдер/карусель** — навигация по карточкам меню
- **Плавный скролл** — навигация по секциям сайта
- **Анимация появления** — секция "Special Dish" появляется плавно
- **Форма подписки** — валидация email и имитация отправки
- **Динамический год** — автоматическое обновление копирайта в футере

### 🔍 SEO & Мета-теги
- Базовые SEO-теги (title, description, keywords)
- Open Graph разметка для соцсетей (Facebook, VK, Telegram)
- Семантическая структура HTML5
- Favicon и Apple Touch Icon

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| **HTML5** | Семантическая структура сайта |
| **CSS3** | Стилизация, Flexbox, CSS Variables, Media Queries |
| **Alpine.js 3.x** | Реактивность и интерактивность без сложных фреймворков |
| **Google Fonts** | Шрифты Open Sans и Playfair Display |
| **Intersection Observer** | Отслеживание появления элементов (через Alpine.js) |
